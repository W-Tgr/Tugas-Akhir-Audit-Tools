# Sistem Manajemen Kuesioner - Alat Audit Berbasis COBIT 2019

Aplikasi mobile berbasis **COBIT 2019** untuk mengelola domain, kategori, level, kuesioner, dan analitik kemajuan pengguna. **COBIT 2019** (Control Objectives for Information and Related Technologies) adalah kerangka kerja global untuk tata kelola dan manajemen TI, yang membantu menyelaraskan proses TI dengan tujuan bisnis, menilai kinerja, dan memastikan kepatuhan. Aplikasi ini dibangun menggunakan **Flutter** untuk antarmuka pengguna yang responsif dan **Firebase** untuk autentikasi, penyimpanan data, dan pengelolaan file, memfasilitasi proses audit berbasis kuesioner.

## Fitur
1. **Login**: Autentikasi pengguna secara aman.
2. **Register**: Pendaftaran akun pengguna baru.
3. **Dashboard Admin**: Ringkasan metrik sistem untuk admin.
4. **Manajemen Domain**: Mengelola domain untuk kuesioner.
5. **Manajemen Kategori**: Mengatur konten berdasarkan kategori.
6. **Manajemen Level**: Mengelola peran pengguna atau tingkat kesulitan.
7. **Manajemen Kuesioner**: Membuat dan mengelola kuesioner.
8. **Kelola Pengguna**: Mengelola akun pengguna.
9. **Unggah Kuesioner**: Mengunggah file kuesioner.
10. **Progress Analytics**: Memvisualisasikan kemajuan pengguna dan penggunaan sistem.
11. **Detail Progress User**: Detail kemajuan untuk pengguna individu.
12. **Kelola Retake User**: Mengelola izin pengulangan kuesioner pengguna.
13. **Dashboard User**: Tugas dan kemajuan spesifik pengguna.
14. **Daftar Domain User**: Daftar domain yang tersedia untuk pengguna.
15. **Informasi Domain yang Bisa Di Retake dan Sudah Terkunci**: Informasi tentang domain yang dapat diulang dan yang terkunci.
16. **Informasi Retake**: Detail tentang kebijakan pengulangan.
17. **Informasi Domain Terkunci**: Informasi tentang domain yang terkunci.
18. **Daftar Kategori**: Daftar semua kategori.
19. **Daftar Level**: Daftar semua level.
20. **Kuesioner**: Antarmuka untuk menjawab kuesioner.
21. **Konfirmasi Jawaban**: Mengonfirmasi jawaban yang dikirim pengguna.

## Instalasi
1. Kloning repositori:
   ```bash
   git clone https://github.com/nama-pengguna/sistem-kuesioner.git
   ```
2. Siapkan lingkungan Flutter dan pastikan perangkat atau emulator terhubung.
3. Konfigurasi Firebase:
   - Buat proyek di [Firebase Console](https://console.firebase.google.com/).
   - Tambahkan aplikasi Flutter Anda (Android/iOS) dan unduh file konfigurasi (`google-services.json` untuk Android, `GoogleService-Info.plist` untuk iOS).
   - Tempatkan file konfigurasi di folder proyek Flutter sesuai petunjuk.
4. Instal dependensi:
   ```bash
   flutter pub get
   ```
5. Jalankan aplikasi:
   ```bash
   flutter run
   ```
6. Pastikan Firebase Authentication, Firestore, dan Storage diaktifkan di Firebase Console untuk mendukung fitur autentikasi, penyimpanan data, dan unggah file.

## Persyaratan
- Flutter >= 3.0
- Dart >= 2.17
- Firebase (Authentication, Firestore, Storage)
- Perangkat Android/iOS atau emulator
